# 문 종류

모든 문 종류에서 수동·자동·겸용 모드를 선택할 수 있습니다.
자동화 방식과 문짝이 움직이는 구조는 별도로 설정합니다.

| 구조 | 등록한 문 |
| --- | --- |
| 한짝 여닫이 | 목재, 패널, 평판, 철제 현관, 아파트 현관, 방범 현관, 방화, 유리 현관, 알루미늄 현관, PVC 현관, 방음, 방충망, 덧문 |
| 양개 여닫이 | 전통 양개, 양개 현관, 유리 양개, 스윙 양개(상하가 열린 살룬형) |
| 피벗 | 중앙축 피벗문 |
| 한짝 미닫이 | 미닫이, 포켓 미닫이, 유리 미닫이 |
| 양개 미닫이 | 자동 양개 미닫이, 양개 미닫이, 로비폰 설치형 자동문 |
| 다중 미닫이 | 3짝 텔레스코픽 |
| 접이 | 접이문, 2단 접이문, 아코디언문 |
| 회전 | 4날개 회전문 |
| 상하·차고문 | 롤링 셔터, 섹셔널 차고문, 틸팅 차고문, 수직 승강문 |

총 **33종**, **13개 이동 구조**입니다. 창호의 실제 제품명·인증·상표를 복제하지 않고
건축용 문 구조와 현관문 외형으로 분류했습니다. 포켓문은 벽을 뚫거나 파괴하지 않고
옆 벽을 통과해 이동하며, 접이·셔터·차고문은 게임용 단순화 모델입니다.
충돌은 회전한 문짝을 작은 구간으로 나눈 축 정렬 상자들로 근사합니다.
