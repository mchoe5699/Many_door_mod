Minecraft 1.20.1 / Forge 47.4.0, Temurin Java 17.0.16, Gradle 8.8 환경에서 검증했습니다.

## 검증한 동작

- 수동·자동·겸용 모드에서 클릭·제어 입력 처리
- 크기·두께·소수 개방각·모드 저장/복원과 부품 생성/축소
- 다른 블록이 있는 공간으로 크기를 변경할 때 원래 설정과 블록 보존
- NaN·무한대·범위 밖 값 거절
- 열림 버튼의 다중 문 제어와 자동 닫힘
- 제거된 문의 이전 링크가 같은 위치의 새 문을 제어하지 않음
- 동작·발판 센서의 엔티티 감지, 문 상태 센서 출력
- 기존 홈넷과 동일한 `OPEN` 속성이 실제 애니메이션을 구동
- 32종·4방향 이동 구조의 충돌/예약 영역, 설치/전체 부품 제거
- 실제 링크 아이템의 선택·연결·해제와 차원 불일치 거절
- 다른 설치자의 설정 변경 거절
- 닫힘 중 엔티티 장애물 감지와 재열림
- 문 부품 하나를 제거할 때 전체 문 제거
- 제어기와 홈넷 연결 데이터 저장/복원
- 서바이벌 제작법 로딩과 크리에이티브 문 아이템 연결
- 회전문의 지속 회전과 해제 시 정지
- 홈넷 호출기 3종, 수신기 5종의 문 열림 메서드 전달 및 대기 상태 차단
